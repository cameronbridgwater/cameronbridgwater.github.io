Selected Projects

Regression

Facebook Post Interaction

Modeled Facebook post engagement with Linear, Ridge, and Lasso regression to understand which features drive total interactions. A good reminder that timing matters, paid boosts help, and not every post deserves the same level of optimism.

  • Focused on post consumers, consumptions, paid posts, and timing.
  • Compared models to find the strongest fit.
  • Translated coefficients into practical engagement insights.
Classification

Fraud Detection Analysis

Built a fraud detection workflow using exploratory analysis and classification models to study imbalanced transaction data. Fraud is rare, messy, and never in the mood to make life easy, so evaluation mattered more than raw accuracy.

  • Used precision, recall, F1, and ROC AUC.
  • Explored transaction type and balance variables.
  • Compared Logistic Regression, Random Forest, and XGBoost.
Clustering

Audio Recommendation with Lyrical Clusters

Created a recommendation project that clusters songs by lyrical themes and age so tracks can be grouped by mood, not just genre. In other words, playlists with a little more personality and a little less algorithmic small talk.

  • Used lyrical topic scores like sadness, feelings, and violence.
  • Built human-readable cluster labels.
  • Designed recommendations around theme-based similarity.
